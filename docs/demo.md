# Material de Demonstração

## Cenário de demonstração

1. Acesse a aplicação em `http://localhost:5000`.
2. Cadastre um produto como `Teclado Gamer` na categoria `Periféricos`.
3. Registre uma entrada de 12 unidades.
4. Registre uma saída de 3 unidades.
5. Valide o resumo financeiro e estoque mínimo.
6. Confirme que a área de movimentações exibe as transações em ordem cronológica.

## Fluxo esperado

- Dashboard apresenta contadores atualizados.
- Produtos aparecem com status `OK` ou `Baixo` conforme o mínimo configurado.
- A API retorna os dados corretos para cada operação.
- Os testes automatizados validam o comportamento principal da aplicação.

## Objetivo de apresentação

Demonstrar o funcionamento de um sistema de estoque completo com operações de gestão, controle de nível mínimo e histórico de movimentações.
